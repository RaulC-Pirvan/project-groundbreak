## Release Notes Cadence

- Update `Unreleased` during active development.
- Create a dated release entry at least once per milestone and/or per tagged release.
- Minimum cadence rule:
  - if a milestone ends without a tag, publish release notes for that milestone anyway
  - if a tag is created mid-milestone, publish release notes for the tag

## Versioning Note

Formal semantic versioning can be introduced later; until then, milestone or tag-based release notes are required.
